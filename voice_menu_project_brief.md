# VOICE CLUB — Мастер-бриф проекта для AI-ассистента

## 1. О проекте и владельце
* **Бизнес:** Караоке-клуб **Voice Club** (Кишинёв, Молдова). Целевая аудитория — гости клуба (преимущественно с мобильных телефонов, iOS / Android), языки интерфейса: **RO (по умолчанию), RU, EN**.
* **Роль пользователя:** Владелец/управляющий клуба, не профессиональный программист, но уверенно работает в **VS Code**, запускает локальный сервер через терминал, пушит код на **GitHub**, настраивает **Cloudflare** и внедряет код через AI-агента **Cline** (по готовым техническим промптам).
* **Как мне помогать (стиль общения):**
  1. Объяснять простым человеческим языком без лишнего академического жаргона.
  2. Давать пошаговые инструкции и **готовые копипаст-промпты для Cline** под каждую задачу.
  3. Сразу предупреждать, если правка кода может затронуть боевые данные в облаке (цены, картинки) или вызвать проблемы с кэшем/деплоем.
  4. Всегда учитывать экономию токенов в Cline: напоминать про новый чат (`+`), режим `Act`, выключенный `Reasoning` и запрет на запуск сервера/браузера агентом.

## 2. Экосистема проектов Voice Club

### Проект А: Интерактивное барное и караоке-меню (`voice-menu`)
* **Боевой домен:** `nicolaisubotin.net` (рабочий домен, в дальнейшем планируется перенос/привязка к основному домену клуба `voiceclub.top`).
* **Админ-панель:** `/pad` (защищена HTTP Basic Auth через переменные окружения `ADMIN_USER` и `ADMIN_PASS`).
* **Суть проекта:** Фотографии страниц бумажного меню с наложенными поверх интерактивными зонами ценников. Гость листает меню, нажимает на цены — позиции собираются в список желаний/заказ. Есть модальные окна для акций (**Promo Set**, **Birthday Offer**) и навигация (**Menu**, **Karaoke** и др.).

### Проект Б: Промо-прокладка для Google Отзывов через NFC (`offer.voiceclub.top`)
* **Суть проекта:** Бармен даёт лояльным гостям NFC-холдер / QR-код → открывается мобильная страница на весь экран с анимированным 3D-барменом (Pixar-style видео `bartender.mp4` на фоне неоновой вывески `VOICE CLUB`). Гость трясёт телефон / жмёт кнопку → бармен трясёт шейкер, из золотой вспышки вылетает карточка с призом (по настраиваемым в админке весам `%` и дневным лимитам) → кнопка перехода на страницу отзывов Google Maps → экран живого купона с 15-минутным таймером и погашением у бармена.

## 3. Технический стек и структура `voice-menu`

Проект построен на чистом фронтенде без сборщиков (деплоится напрямую из GitHub в Cloudflare Pages):

```text
voice-menu/
├── index.html                  # Гостевое меню + полноэкранные модалки (#promo-modal, #birthday-modal, корзина)
├── pad.html                    # Админ-панель (Basic Auth)
├── config.json                 # Локальный бэкап / шаблон конфига (секции, картинки, координаты цен, настройки UI)
├── wrangler.toml               # Привязки Cloudflare: KV (CONFIG) и R2 (BUCKET / voicemenu)
├── .dev.vars                   # Локальные логин/пароль для wrangler pages dev (в .gitignore)
├── assets/
│   ├── css/styles.css          # Стили, мобильная адаптация, эффекты заголовка MENU, свайп-слайдеры
│   ├── js/app.js               # Логика меню, свайп-слайдеры, корзина, локализация
│   └── js/admin.js             # Визуальный редактор зон цен, дублирование зон, сдвиг стрелками клавиатуры
├── locales/                    # Файлы переводов (ro.json, ru.json, en.json)
└── functions/                  # Cloudflare Pages Functions (бэкенд)
    ├── _middleware.js          # Авторизация Basic Auth для /pad и /api/admin/*
    └── api/
        ├── config.js           # GET /api/config — чтение конфига из Cloudflare KV (ключ "menu-config")
        ├── admin/config.js     # PUT /api/admin/config — запись конфига из админки в KV
        ├── admin/upload.js     # POST /api/admin/upload — загрузка фото страниц меню в R2
        └── images/[[path]].js  # GET /api/images/* — раздача загруженных фото из R2
```

## 4. Что уже реализовано и работает в `voice-menu`
1. **Визуальный конструктор цен в `/pad`:**
   * Загрузка фото страниц меню в Cloudflare R2, рисование и ресайз зон цен мышкой.
   * **Кнопка «Дублировать»** у каждой зоны (копирует точные размеры и стили, смещая дубликат чуть ниже оригинала).
   * **Точная доводка с клавиатуры:** `Arrow` сдвигает выделенную зону на `0.1%`, `Shift + Arrow` — на `1%`, `Alt + Arrow` — меняет ширину/высоту на `0.1%` (с защитой от срабатывания внутри полей ввода).
2. **Навигация и оформление:**
   * Кнопка **`KARAOKE`** в меню навигации.
   * **4 переключаемых стиля** и анимация появления заголовка **`MENU`** (выбираются в админке во вкладке Navigation).
3. **Полноэкранные свайп-слайдеры для `PROMO SET` и `BIRTHDAY OFFER`:**
   * Открываются строго в полноэкранных модалках (`100vw × 100dvh`, исключены из основного потока главной страницы) с закреплённой сверху кнопкой **`‹ НАЗАД`**.
   * Полупрозрачный тёмный фон с лёгким матовым стеклом (`rgba(12, 12, 22, 0.80)`, `backdrop-filter: blur(5px)`).
   * Динамическое число слайдов (зависит от числа загруженных в админке вертикальных карточек: при 1 карточке стрелки и точки скрыты, при 2+ появляются автоматически).
   * Нативный свайп (`scroll-snap-type: x mandatory`), контрастные боковые стрелки с покачиванием правой стрелки, мини-точки внизу и оптимизация 60 FPS (`translateZ(0)` + `requestAnimationFrame`).

## 5. Критически важные правила и «грабли» проекта (не повторять!)
* **Сохранность боевых цен при деплое:** Все реальные цены и настройки живут в облачной базе **Cloudflare KV** (`CONFIG` → `menu-config`), а фото — в **Cloudflare R2**. Обычный `git push` и деплой кода **не затирают** базу KV. Но перед большими изменениями всегда делать бэкап: скопировать JSON с `https://<домен>/api/config` в локальный `config.json` (отформатировать в VS Code через `Shift + Alt + F`).
* **Локальная разработка (`npx wrangler pages dev . --port 8788`):**
  * Локально картинки с путями `/api/images/...` не отображаются (404), так как лежат в облачном R2, а не на диске ПК — это нормально.
  * Чтобы обновить локальную базу KV из файла `config.json`:
    `npx wrangler kv key put --binding=CONFIG "menu-config" --path=config.json --local --preview false` (и повторить с `--preview true`).
  * В браузере после любых правок обязательно делать жёсткое обновление без кэша (**`Ctrl + Shift + R`**).
* **Ограничения для агента Cline:**
  * Встроенный `chrome-devtools` MCP в этой среде глючит и уходит в бесконечный цикл — в промптах **всегда запрещать** запуск браузера и сервера.
  * Для экономии средств использовать быстрые модели (`Flash` / `DeepSeek`) с выключенным **`Reasoning: Off`**, открывать новый чат (`+`) под каждую задачу.
* **Git / VS Code:** Перед нажатием *Commit & Push* обязательно писать короткое сообщение в поле *Message*, иначе VS Code открывает вкладку `COMMIT_EDITMSG` и ждёт её сохранения.
